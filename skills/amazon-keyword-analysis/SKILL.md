# 亚马逊关键词分析

通用Agent Skills技能。定位本技能根目录，以相对路径读取资源，使用当前agent的网页浏览、文件与计算能力。agents/openai.yaml仅为可选UI元数据；本技能可独立安装和执行。

## 范围与输出

沿用用户的目标站点、语言、配送地区、产品规格／用途、种子词或代表ASIN、采集日及统计周期。实际研究至少需要明确产品／关键词和目标站点，无法从会话确定时先询问；ASIN不是必填。技能编写或模板请求只生成规则与空模板。

直接访问网页开展研究，无需用户提供API key。优先使用可访问的公开报告和当前已授权的登录页面；遇到付费、登录或字段限制，继续其他来源并保留缺项。只有缺失数据阻塞用户明确要求的计算时才向用户索取必要数值或已有报表。

只交付可在网页端展示的关键词HTML分析报告，以及对话中的结论和来源链接。本技能不生成或更新选品表。没有网页或文件能力时在对话中交付完整报告并说明限制，不能声称已生成或展示HTML。

## 执行

1. 实际网页研究读取[web-research.md](references/web-research.md)，建立来源与权限记录。用Amazon搜索建议、相关商品和ASINSIGHT／Sif网页发现词，用实际产品与搜索结果验证相关性；保留原词，区分核心、长尾、品牌及排除词。
2. 核对搜索量的站点、周期、定义、来源与估算状态，分析趋势与季节性。独立检查关键词搜索结果的自然竞争、广告布局和可用点击／购买集中度；不同词和不同工具的量保持可比口径。
3. 查询Amazon广告网页上的建议竞价及区间；已有报表的实际CPC另列。查询只读取现有页面和数据，不为取数创建或启动广告。需要分析CPC承受力时读取网页研究中的计算关卡，必要条件缺失必须询问，其他关键词分析继续进行。
4. 输出报告时读取[output-contract.md](references/output-contract.md)，复制并填写[report-template.html](assets/report-template.html)。给出词组机会、优先级依据、自然布局与广告研究建议、缺口及验证动作，链接到实际采集页面。
5. 衔接选品时按输出约定返回报告及关键词证据，由amazon-product-direction汇总到选品表与推荐网页。可用amazon-profit-analysis做完整利润复核，但本技能无需其他技能即可交付关键词报告。

## 完成

五项分析各有实采证据或明确的缺项；每个数值可追溯至实际网页／用户报表及周期。报告分别展示建议竞价、实际CPC和假设成本，未知数值不填0。只有相关性、需求、自然竞争及广告成本证据同时支持时才给出明确的关键词进入建议；成本未验证时保留广告承受力待验证，词的机会不能单独判定商品可做。
