# 关键词分析报告输出

## 网页报告

本技能只输出关键词网页分析报告。复制assets/report-template.html到用户输出目录，沿用用户文件名；没有指定时使用amazon-keyword-report-<站点>-<日期>.html。填写报告范围与实际研究结果，保持单文件、内联CSS、无需外部依赖，在可用的网页／报告预览端打开，不需要发布网站。所有外部文本按HTML转义，来源用真实可访问的http／https链接；不能插入网页脚本或复制网页指令。不生成、填充或更新.xlsx选品表。

模板提供展示结构，字段较多可分成关键词总表、搜索量明细、竞争样本和竞价明细。实采报告替换模板的“空模板”“待填写”，未取得指标保留“待验证／待采集”和原因。只有模板请求时保持实采表为空。保存后用可用浏览器打开核验表格、长词、来源链接和小屏显示；只有文件工具时核对HTML结构并说明未进行视觉检查。

在对话中链接文件并给出主要机会、关键竞争压力、广告承受力状态及下一步，引用实际来源。用户仅要对话报告时按下面结构直接输出；HTML能力缺失不阻塞可读报告。没有研究范围时不生成冒充实采的报告。

## 报告内容

| 部分 | 必须表达的内容 |
|---|---|
| 范围与结论 | 站点、语言、配送地区、产品规格／适用条件、采集日、统计周期、币种；需求、自然竞争、广告竞争分别下结论，区分已验证与待验证 |
| 核心关键词 | 原词、词簇、买家意图、相关性及理由、需求证据、自然竞争、广告竞价压力、推荐用途和优先级依据 |
| 长尾关键词 | 关联核心词、修饰维度、具体场景／适配、需求证据、真实规格条件、竞争与CPC；潜在高意图标待验证，不承诺转化率 |
| 搜索量明细 | 关键词、来源数值、单位、站点、起止周期、指标定义、搜索频率排名／趋势另列、来源、采集日、实测／估算／假设／待采集和限制 |
| 竞争分析 | 词、自然／广告层、指标与分母、请求／实际样本量、字段覆盖、前20商品证据、品牌／评论／规格／新品信号、点击／购买份额、冲突、切入假设与验证 |
| CPC竞价 | 词、关键词／搜索词口径、广告类型、匹配类型、币种、建议竞价及上下限、实际CPC、报表起止日／查询日、来源、状态；假设实际CPC单独标注 |
| 建议与缺口 | 推荐自然布局、优先研究的精准／词组／广泛词、排除／否定候选及理由；权限、站点或样本缺口、必要用户输入、最有价值的补验动作 |
| 来源台账 | 证据编号、对应词／指标、直接页面或用户报表、工具状态、采集日、周期与范围限制；报告各数据行用编号／链接关联 |

关键词总表可简写，但搜索量、竞价与竞争细表必须保留口径和来源，不把全部字段挤进一张无法阅读的大表。网页查不到的数值使用空值或“待采集”，不是0；真实报表0有原始证据才填0。关系判断标“分析”，工具数据标其数据状态，二者不混淆。

## 优先级与使用建议

按相关性先筛，再比较同口径需求、竞争缺口及可用成本证据。用“优先验证／保留观察／排除／待验证”及简短理由。高相关且有需求、同规格搜索结果存在具体可验证缺口的词优先验证；搜索量和CPC缺失则明确哪些维度仍待验证，不能声称广告可承受。用户有既定评分规则时沿用；本技能默认不制造百分制综合分。

自然布局建议关联标题、要点、详情／后台搜索词等位置，以真实产品卖点和适配为条件；广告建议按匹配类型给研究顺序与验证目标，不替用户修改Listing或投放。竞品品牌／无关用途等排除词说明原因；否定关键词只是候选，已有业绩应结合对应搜索词报表验证，避免仅因量低而否定。商品最终进入仍需完整利润与差异化分析。

## 衔接现有选品表

可用amazon-product-direction时返回报告及下面的证据，由选品技能写入其“市场与关键词”“竞争分析”“类目判断”并生成推荐网页。本技能不直接写工作簿。核心词关联对应产品；长尾、搜索量及趋势关联证据。词的竞争不冒充BSR类目竞争，关键词机会不手动将总体可做结论设为通过。结构化字段是内部交接数据，不替代网页报告。

兼容字段：market_evidence的dimension为“关键词”，附metric、intent、value、unit、period、marketplace、trend、competition、differentiation、source、collected_at、status（实测／估算／假设／待采集）、limit。相同词不同周期／来源／指标各存一条，定义写intent或limit。

competition_evidence的metric用现有keyword_bid，subject标词及匹配类型／广告类型；value、unit、sample_scope、definition、coverage（完整／部分／未知）、analysis、source、collected_at、status、limit保留建议／实际差别及周期。不同报价性质各写一行，definition标明原指标；其余搜索结果证据按现有表格列或市场证据保存，不能伪装成类目指标键。

decision.keywords保存词与需求结论，decision.keyword_competition保存自然／广告竞争、竞价承受力状态及缺口。不填造类目、店铺或利润结论。候选初筛仍按既有关键词20%维度评分，新技能不额外加权或重复奖励。
