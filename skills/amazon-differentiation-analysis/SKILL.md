# 亚马逊差异化分析

通用Agent Skills技能。定位本技能根目录，以相对路径读取资源，使用当前agent的网页浏览、文件、计算与用户输入能力。agents/openai.yaml仅为可选UI元数据；本技能无需其他技能或API key即可执行。

## 范围与输出

沿用目标站点、产品／关键词或竞品ASIN、规格、目标买家／场景及采集范围；研究实际产品时，无法从会话确定站点和产品方向先询问。已有自有方案、报价与成本基线直接使用；没有自有方案时先提出条件明确的改进方向。技能编写或模板请求只生成规则及空模板，不询问真实商品费用。

通过可访问的商品、评价、品牌、说明书与报价网页，以及用户提供的评论或报价文件取证。登录／评论权限不足时记录覆盖与缺口，继续可完成的研究；不能把无法查看当作不存在问题。只交付差异化HTML网页分析报告，不生成、填充或更新选品表。

## 执行

1. 读取[review-research.md](references/review-research.md)，选取同用途、可比规格的代表竞品，建立产品对比与1–3星评论证据。按独立评论去重，记录星级、日期、变体、采样范围和来源，分别归类三项问题，保留不适用的“其他”。
2. 从重复抱怨和竞品可核实的覆盖缺口推导需求，区分已观察的问题、待验证原因和方案。每个方案明确目标人群、真实使用条件、改变内容、相对竞品的区别与证据强弱，不把差评频次当全市场投诉率。
3. 读取[cost-and-validation.md](references/cost-and-validation.md)，拆分每单件增量费用、一次性投入与可选分摊，说明报价依据、币种、基线和范围。阻塞用户要求的数值计算时必须询问必要输入，成本未知保留待报价；其他方案研究继续进行。为每个方案定义对照、测试条件、指标、验收标准与成本验证动作。
4. 读取[output-contract.md](references/output-contract.md)，填写[report-template.html](assets/report-template.html)，在网页端展示竞品与差评分析、差异化方案、增量成本、验证计划、优先级及缺口，提供来源链接。候选方案与已完成验证分开标注。
5. 衔接选品时返回报告及可追溯证据，由amazon-product-direction统一写入选品表与推荐网页。需要完整利润复核时使用可用的amazon-profit-analysis，必要条件缺失必须追问；差异化不能绕过利润否决。

## 完成

报告中的三类问题各有实际证据或明确的未发现／缺项说明，方案关联具体问题和竞品覆盖，增量成本有拆分及来源或待报价状态，验证方式有可判断的通过条件或待确定输入。没有重复证据时提出有限的待验证假设，不凑方案；未实测不称改进已有效，未知费用不填0，成本与利润未验证不判商品可做。
