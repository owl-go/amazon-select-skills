# 增量成本与验证

## 方案结构

每个方案有独立ID，关联问题与评论证据ID。写明目标买家／场景、基线规格、具体改动、预期解决的问题、竞品已覆盖部分、剩余差异、制造可行性和可能引入的副作用。功能、尺寸、耐久或场景主张须有验证路径；更换颜色、文案或附件只有满足已证实需求时才构成有效方案。

“建议改动”“供应商确认可制造”“已打样”“已测试通过”分开保存。根据证据力度、问题影响、可实现性、成本和验证难度给出“优先验证／保留观察／暂缓／待报价”，附具体理由，不输出未经请求的综合百分制分。没有可证明的缺口时如实说明，不凑方案。

## 增量成本

以同一自有基线与改进后方案比较；竞品零售价或猜测采购成本不能作为自有基线。每项标增加／减少、金额或范围、销售单位、币种、规格、MOQ、报价日期、来源、费用归属及实测／报价／估算／假设／待报价状态。

| 类型 | 应核查的变化 | 处理 |
|---|---|---|
| 持续单件费用 | 材料、零件、加工、装配、质检、包装、头程、履约、仓储及适用税费变化 | 按同销售单位算改进后费用减基线费用；改变重量／尺寸或价格后核查适用费用，不假定平台费用不变 |
| 一次性投入 | 设计、模具、打样、专用测试／必要认证或工装 | 与持续成本分列；列真实项目和依据，没有项目不泛加费用。分摊需明确数量与口径 |
| 潜在收益或损耗变化 | 更低返修／退货、价格溢价、转化改善 | 有证据且归因可比时另做情景；没有数据不能拿预计收益抵扣已知增量成本 |

持续单件净增成本ΔC＝Σ(改进后同口径费用−基线费用)。一次性投入F单列；只有分摊数量Q明确且>0时才给F/Q，标明假设及适用数量。一次性费用若已含在单件报价中不再摊一次。不同MOQ报价、整票与单件、含税与不含税金额需先统一；跨币种需要方向、日期和来源明确的汇率。

基线或改进报价未知时列成本驱动项和待报价，不编造具体区间。可靠的同规格报价可给有来源的预算范围，说明并非实际成交成本；自拟数量、费率或收入假设需用户明确允许。只有部分费用已知时展示局部增量，不宣称总增量。必要条件不能从现有资料或授权网页取得、且阻塞所请求的数值计算时，一次列明向用户询问：缺失规格／数量、基线与改进金额、币种／汇率、含税／分摊口径或报价范围。没有完整利润测算请求时不强求全部采购与广告参数。

已有同售价的完整基线时，持续成本增加对单件利润的局部影响为−ΔC；对毛利的影响只计入毛利成本范围内的ΔG，毛利率变化为−ΔG/售价。仓储、退货和一次性分摊按利润模型的独立归属处理，不能全部塞进毛利成本。改变售价或假设退货减少时重新计算适用费用与广告分母，不能用旧利润直接加差价。

进入完整利润复核时，由可用的amazon-profit-analysis核验全部必要输入；缺项必须追问。沿用既定目标ACoS＋5个百分点毛利门槛（30%对应35%，含边界）及完整成本净利>0规则，已知失败时方案标“暂缓／淘汰（利润否决）”，不能用差异化高分抵消。只是局部增量分析时利润保持待验证，不宣称达标。

## 验证计划

每个方案列出：待验证假设、原基线／竞品对照、改进样品、测试条件与步骤、样本和批次设计、评价指标、通过标准、记录方式、资源／费用及决策动作。没做过的实验全部标计划；供应商宣称、图片或买家推测不作实际测试通过。

| 问题方向 | 验证设计 | 验收应明确什么 |
|---|---|---|
| 质量与耐用性 | 复现评论对应负载、环境和失效部位；相同条件下比较基线与改进样的强度、重复使用、密封、磨损等相关表现 | 具体失效定义、测试时长／循环／载荷、允许失效与功能保持标准，兼看重量和操作副作用 |
| 尺寸与适配 | 按已核实的型号、尺寸边界与公差测试，检查安装／拆卸、稳定性和非适配情况 | 覆盖清单、边界尺寸、安装成功及稳定标准；标准来自真实规格，不能虚构兼容型号 |
| 使用场景缺失 | 目标用户在真实场景完成操作任务，对照配件、收纳、清洁或携带方案 | 任务成功、耗时、操作困难或维护指标及场景限制；区分功能测试和文案理解测试 |
| 成本与制造 | 索取同规格、同数量的两版报价，打样检查尺寸重量、加工良率、装配与质检流程 | 费用包含范围、单位成本、MOQ、报价有效期和费用变化；供应商报价不等于量产实绩 |

验收阈值来自用户性能目标、原始规格、已取得的测试依据或明确标为“拟定”的工程目标。缺关键条件时写待确定并询问必要输入；可先提出可测量的指标及阈值确定办法，不能硬套全品类统一循环数、跌落高度或公差。涉及正式标准／认证主张时核查当前官方资料与适用产品范围，实验计划不等于合规或认证结论。

实际验证后记录样品版本、条件、数量、测量结果、是否达到预先标准及残余问题。通过才升级对应性能证据；失败时修改或停止方案，不能仅删去失败结果。用户价值与愿付价格可通过后续访谈／小样试用验证，但本研究不擅自联系买家、承诺采购或启动投放。
