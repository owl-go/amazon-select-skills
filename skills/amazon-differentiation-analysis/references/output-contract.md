# 差异化网页报告

本技能只输出差异化网页分析报告，不生成、填充或更新Excel选品表。复制[report-template.html](../assets/report-template.html)，填写实际研究数据，保存为用户指定路径或amazon-differentiation-report-<站点>-<日期>.html，在当前agent可用的网页／报告预览端打开，并在对话中给出链接、主要方案和必要缺项。

单文件HTML、内联CSS、无外部依赖，外部文本按HTML转义，来源使用真实http／https链接。实际报告替换“空模板”“待填写”，未知指标保留待采集／待报价／待验证及原因。模板请求保持实采区为空。预览受限时核验结构并说明未做视觉检查，不绕过限制；没有网页／文件能力时交付完整可读报告并说明限制，不宣称已展示HTML。无需部署或公开发布网站。

## 报告内容

| 部分 | 必须保留的内容 |
|---|---|
| 范围与结论 | 站点、产品／规格、目标买家与场景、代表竞品及入样理由、评论时间窗／星级筛选／排序／实际数量、采集日、成本币种与自有基线；主要机会与证据强弱 |
| 竞品对比 | ASIN／父体、品牌、可比价格与规格、材料结构、尺寸／适配、场景与附件、当前版本，需求覆盖状态和来源；未知不当未覆盖 |
| 三类差评 | 分类、统一问题、独立评论数／有效差评总数、涉及父体／品牌、近期与版本分布、影响程度、买家需求、可能根因与证据；样本比例明确分母 |
| 评论证据 | 证据ID、ASIN／父体、评论ID／链接、1–3星、日期、变体、忠实摘要、主分类、问题、场景、次要标签、来源、采集日及限制；不披露无关个人信息 |
| 差异化方案 | 方案ID、关联问题／证据ID、目标用户与条件、基线和具体改动、相对竞品的区别、预期收益与副作用、证据状态、优先级及理由 |
| 增量成本 | 方案／费用项、基线与改进金额、差值／单位、币种、持续或一次性、MOQ／分摊量、包含范围、报价来源与日期、估算或待报价状态；总增量与局部金额分开 |
| 验证方式 | 方案ID、假设、对照、测试条件、样本／批次、指标、通过标准或待确定条件、资源与费用、计划／已测状态、真实结果及决策动作 |
| 来源与下一步 | 工具与页面访问覆盖、数据来源、权限／版本／成本缺口、必要用户输入、报价与验证动作；利润未复核说明待验证 |

质量与耐用性、尺寸与适配、使用场景缺失三项各有结论。没有命中的分类写“本次有效样本未发现”，附范围；没能取得评论写“待采集”，不能写无需求。方案数由真实证据决定，无充分证据时不凑方案或数字。

报告主线为“买家抱怨→真实需求→竞品覆盖缺口→差异化方案→增量成本→验证门槛”。预算与实验计划不冒充真实量产成本或验证结果；局部成本不冒充完整净利，利润否决方案不能推荐实施。

## 交接给选品技能

完整选品流程中返回本报告及可追溯证据，由amazon-product-direction统一生成工作簿及推荐网页。本技能不直接操作选品表。可提供以下现有字段，保持各自含义：

- reviews：asin、stars（1–3）、reviewed_at、summary、category（三类或其他）、issue、scenario、improvement、sampling_scope、review_url、source、collected_at、note。主分类统计，去重规则与缺变体记录写sampling_scope／note。
- 对应候选的main_pain与screening_basis：保存重复问题、覆盖缺口和评分证据；差异化分仍属于现有25%初筛维度，由选品技能根据证据给1–5分，缺证据留空，不额外加权。
- decision.differentiation：保存方案摘要、适用规格、增量费用性质、报价／验证状态、主要限制和下一步。详细方案ID、成本表及验证记录通过报告交接，不塞入未支持的生成器字段。

增量采购、包装或其他成本仅供选品技能更新对应自有方案，替换为改进后的完整金额而非把差值误当全成本；已计入报价的费用不重复加。新增费用需要保留归属、币种与分摊口径。需要完整利润判断时执行利润技能的输入关卡，不手动覆盖选品表的利润否决公式。
