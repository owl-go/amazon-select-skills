# 选品网页推荐报告

本技能交付两件成果：Excel选品表作为研究与成本明细，HTML网页报告展示推荐的商品／自有产品方向及推荐理由。类目、关键词、利润、差异化技能只返回网页报告和证据，由本技能汇总进工作簿；调用其他分析技能不会转移表格的输出职责。

## 网页生成与展示

复制[report-template.html](../assets/report-template.html)，填写与选品表一致的实采结果，保存为用户指定路径或amazon-selection-report-<站点>-<日期>.html。使用单文件HTML、内联CSS，无需外部服务；外部文本按HTML转义，来源使用真实http／https链接。用当前agent可用的网页／报告预览端打开，在对话中给出网页报告和.xlsx链接及主要推荐。无需部署网站或设置公开访问。

若浏览器预览受限，核验HTML结构并说明未完成视觉检查，不绕过限制；网页／文件能力缺失时交付完整可读的推荐报告并说明具体缺失，不声称已完成网页展示。模板请求保持推荐与实采表为空，不写虚构推荐。

## 推荐内容

每个推荐项关联选品表中的产品／自有方案、选品方法和参考ASIN／来源；参考ASIN是研究对象，不代表购买竞品或已掌握竞品成本。网页至少显示：推荐层级、商品／方向、目标买家／场景、主选品方法、初筛得分与覆盖率（已有时）、市场／竞争／关键词／差异化证据、利润状态、推荐理由、主要风险／缺口、下一步。

推荐理由用“具体证据→产品机会→验证或行动”表达，附对应来源；不能只写热销、蓝海、低竞争等标签。可对最值得研究的候选展开解释，数量由实际证据决定，不设必须凑够的推荐数。展示主要暂缓／淘汰项及原因，方便用户比较。商品评价星级与百分制初筛得分分别标注。

## 推荐与利润状态

- 初筛可展示“优先研究／保留观察”，说明排序依据及缺项；成本未知时利润标待验证，不能推荐为已可做或已盈利。
- 深度研究仅在市场、三层竞争、关键词、差异化和完整成本利润证据成立时展示“可打样”，说明结论适用的规格、价格和广告情景。利润门槛达标只是一项证据，不单独触发可打样。
- 已知毛利不达门槛或完整成本净利≤0的方案展示“淘汰（利润否决）”，从积极推荐中排除，其他高分不能抵消。
- 没有符合条件的商品时明确“当前无可打样推荐”，可另列有证据的待研究方向及补验动作，不放宽条件凑推荐。

## 一致性与证据

报告保留站点、类目／关键词、采集日、币种、研究阶段和来源台账；推荐顺序与最新选品表对应，解释研究优先级与最终进入判断的区别。Excel重算后的利润、评分、缺项及否决状态是网页引用结果的依据，不在HTML中重新用另一套公式计算。报告提供选品表名称／同目录相对下载链接及各分析报告链接（已有时）；文件缺失就说明缺失，不放无效下载链接。差异化方案标报价、打样和测试状态；增量费用更新为改进后完整金额再重算，不将差值误当全成本，也不重复计入已含费用。

利润分析结果的广告分母、费用范围和情景必须完整保留。运营分摊写独立成本项并扣除，避免重复计费；整体订单广告成本不可写进仍按售价×ACoS计算的旧公式。本技能负责同步公式和口径说明，或单独列出整体订单情景。网页与工作簿出现冲突时先修正，最终交付不得同时出现“利润否决”和“推荐可做”。
