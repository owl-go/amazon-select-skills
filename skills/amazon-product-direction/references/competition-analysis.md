# 市场竞争分析

按类目、核心关键词、产品／店铺三层分析。用户给出的阈值是选品经验规则，不是平台官方标准；满足某项只表示对应机会信号。竞争初筛仍占25%，利润仍独立否决。

## 工具选择与降级

已有用户提供、可用的Sorftime key时，优先使用Sorftime的BSR类目分析及导出。调用以当前官方文档和实际可用工具为准；密钥通过当前agent的安全凭据渠道使用，报告、工作簿和仓库仅记录工具名称及数据来源。

未提供key，直接降级为Flapen＋ASINSIGHT，不为选择工具阻塞任务：

- [Flapen类目研究](https://flapen.com/research/us)：找细分市场，查看评论门槛、品牌集中、产品价格／评论／年龄等可获得信息。先确认目标站点覆盖，工具的niche或关键词样本不能自动当成类目BSR Top100。
- [ASINSIGHT](https://www.asinsight.com/)：补充ASIN、关键词、排名、流量及点击／转化集中情况。关键词Top3点击占比不能替代类目品牌或店铺垄断率。
- 两者配合Amazon类目榜单、商品页、卖家页和用户导出，按下面相同字段补证。注明降级路径及逐项覆盖，未知数据保持待验证。实际权限不足时，先完成能查的部分，再向用户索取缺失字段的导出或截图；不声称功能完全等价，不编造API。

## 类目方法一：BSR Top100

固定站点、配送地区、细分类目节点、榜单地址和采集日，保留Top100榜单条目及ASIN、父体、品牌、卖家、上架日期、评论数、星级、卖家类型、A+和视频。默认以榜单100个条目为分母，记录父子体共享情况；如工具已合并父体，另写实际分母与去重规则，不能把少于100条的结果称为完整Top100。日期、评论或卖家类型缺失时分别显示该指标的有效数量。

| 指标 | 用户规则 | 口径与解释 |
|---|---|---|
| 近3个月新品占比 | ≥10%为新手友好信号 | 采集日前3个日历月至采集日，含首尾边界；新品数÷完整Top100 |
| 近6个月新品占比 | ≥20%为新手友好信号 | 同上，窗口6个日历月；分别报告两个信号，不额外要求同时满足 |
| Top100上架时间分布 | 新品占比越大，机会越多 | 展示3／6／12个月及更早的分布，窗口可重叠；Date First Available仅是上架时间代理值 |
| 评论时间分布 | 按用户所述图：左侧多竞争小，右侧多竞争大 | 先记录横轴、时间方向、区间和统计对象，核实图上左右对应的实际含义；时间方向相反时按真实含义解释，轴未知则待验证 |
| 评论数量分布 | 低评论区多竞争小，高评论区多竞争大 | 横轴从低到高时对应左低右高；记录分桶及数量，不用均值替代分布 |
| 品牌垄断程度 | <45%可接受 | 保留工具的品牌聚合范围、分子、分母及周期；45%本身不属于低于45% |
| 店铺垄断程度 | <45%可接受 | 区分品牌与卖家ID；保留TopN／销量／销售额等原定义，定义不明时待验证 |
| Amazon自营占比 | <19%为有利信号 | 以实际销售方识别自营；FBA是履约方式，不能当成自营；19%本身不通过此信号 |
| FBM占比 | 越高越有利 | 同口径对比类目或历史，记录比较基准；没有固定通过线 |
| A+视频占比 | 越少越有利 | 记录工具定义；A+、视频、同时有A+和视频分别统计，不能擅自合并为一个比例 |
| 整体星级 | 越低越有改善机会 | 标明简单平均或销量加权及覆盖；结合1–3星质量／适配／场景差评判断改善可行性，没有固定通过线 |

如果工具只有“上架年龄×评论数”的图，准确标记它的轴和数据范围；不能把它称为买家评论日期分布。图形“左／右”必须转成实际区间结论。较低星级还需确认差评可解决、增量成本可承受。

对品牌／店铺垄断，缺工具定义时向用户索取报告口径，或明确选择并标注代理指标。代理值可辅助解释，不能冒充原指标套用45%阈值。完整样本未知项不能按0计入比例；可报告已知数量、覆盖率和可能上下界，但结论保持待验证。

## 类目方法二：Top50低评论卖家

采集同站点、同细分类目的BSR前50名，记录榜单排名、ASIN、父体、评论数量、评论口径、代表销售方seller ID及来源。这里的rating少于1000指评价数量，商品星级另存1–5分。

筛选评论数严格<1000的条目，以seller ID去重，低评论卖家数严格>20（至少21家）为新手友好信号。一个卖家有多个低评论商品仍计一家；同时报告低评论商品数、去重卖家数和总卖家数。恰好1000不计，恰好20家不通过。身份缺失、评论缺失或样本不足50条时报告覆盖及已知下限，不能冒称完整判断。

方法一和方法二是两条互补的类目证据路线。实际可得哪条先做哪条；均可得时交叉核验，冲突需解释样本与统计定义，不能任选有利的一条当整体结论。原关键词前20的评论壁垒、SKU、近一年新品及错配规则仍按[research-method.md](research-method.md)执行，三个样本分别保存。

## 核心关键词：CPC竞价

在Amazon广告后台的关键词投放／竞价界面查询核心词及高相关长尾词。记录原词、站点、日期、货币、匹配类型（广泛／词组／精准）、建议竞价及区间、广告类型、数据截图或导出来源。仅查看，不为查询创建或启动付费广告。已有广告记录另列实际CPC及统计周期；建议竞价不能写成已发生CPC。

同站点、同匹配类型对比竞价压力，不设置用户未指定的统一“低CPC”阈值。Flapen／ASINSIGHT的广告或流量观察可作辅助，后台竞价不可得时标明缺项，需要测算则向用户索取后台数据。

联动利润分析：以预计实际CPC做明确的假设情景，广告归因订单转化率CVR＝订单÷点击，广告归因客单销售额＝单件售价×每单件数（或用户实际客单额）。预计ACoS＝CPC÷(CVR×客单销售额)，目标ACoS下可承受CPC＝目标ACoS×CVR×客单销售额。采用相同收入、币种和归因口径；未知CVR、每单件数或收入基础时先向用户追问，不能靠竞价直接推算ACoS或利润。执行完整利润测算时按利润技能必要输入关卡处理。

## 产品竞争：店铺实力

按代表竞品关联真实seller ID及品牌店铺，区分品牌所有者和销售方。逐项记录观察、证据、缺项以及对自有方案的影响：

| 判断项 | 对应工具与动作 |
|---|---|
| 评论数量与星级 | Amazon商品页／Sorftime或降级数据；比较多款产品的累计评价、近期增长、评分和重复差评，区分店铺feedback与商品评价 |
| 品牌商标 | Amazon品牌页、目标销售国家的官方商标数据库；查权利人、状态、类目、品牌一致性；A+或品牌名不能证明商标注册 |
| 国家、地区 | Amazon卖家公开公司信息；记录原始主体、国家／地区和来源，不从卖家名字猜测实力或实际所在地 |
| 产品列表 | 卖家产品列表／品牌店铺；记录在售SKU、类目集中度、系列尺寸颜色覆盖、新品和相邻扩品，说明未覆盖范围 |
| 文案与图片 | 商品详情页；比较本地化、卖点、适配说明、实拍／场景图、A+和视频，指出可见差距与实现成本 |
| 站外推广 | Keepa辅助查看价格、BSR及可获得的促销变化，网页搜索ASIN、品牌及产品名，核查品牌官网、公开社交媒体、测评／联盟内容、促销站点及可访问的广告资料库；记录渠道、推广链接、日期、活动及频次；仅凭查不到结果不能断言无站外推广 |

[Keepa历史记录](https://github.com/keepacom/api_backend/blob/master/src/main/java/com/keepa/api/backend/structs/Product.java)可帮助定位需核查的活动时间，但价格下降或BSR变化本身不能证明站外推广，也不能据此推断具体渠道；能否显示某种促销字段以实际权限与数据为准。站外推广查询记录搜索式、日期范围及已查渠道。命中页面需核对品牌／ASIN对应关系，区分官方、付费、联盟、用户自发内容与无法确认的推广；频次只是所查样本，不推算未公开的预算或销售贡献。商标正式状态以[USPTO](https://www.uspto.gov/trademarks/search)或对应国家官方数据库为准。

## 写入与评分

在“竞争分析”页按层级和方法保存：研究对象、指标、观察／数值、单位、样本范围、统计定义、覆盖状态、判断规则、信号／分析、来源、日期、数据状态与限制。在主表“竞争程度”写有证据的摘要，引用具体指标／店铺；在“类目判断”记录三个层次的结论、工具路径和缺口。

维持原四维权重，不为增加指标重复奖励竞争分：1分为明显集中、自营或评论／SKU壁垒且缺可行切入点；3分为部分友好信号、词或店铺进入点仍待验证；5分需要类目机会、关键词广告承受力、店铺／SKU切入空间都有证据支撑。2／4分为相邻情况，关键证据未知留空；初筛可先依据已得线索评分并明确限制，深度研究仍需完成三层分析。方向性信号和单项达标都不能替代综合进入判断。
