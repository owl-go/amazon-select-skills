# 市场竞争分析

按类目、核心关键词、产品／店铺三层分析。用户给出的阈值是选品经验规则，不是平台官方标准；满足某项只表示对应机会信号。竞争初筛仍占25%，利润仍独立否决。

## 类目容量与竞争

独立类目研究或容量分析优先使用可用的amazon-category-analysis技能，读取其容量方法与输出约定。选品技能自身保留完整的[类目竞争规则](category-competition.md)，独立安装也能执行BSR Top100／Top50分析；实际分析类目竞争时必须读取该参考。

类目Top100、Top50和关键词前20各自保存范围、分母与覆盖。前20评论壁垒、SKU、近一年新品和错配仍按[research-method.md](research-method.md)执行。类目友好信号不能代替关键词广告承受力与店铺切入空间。Jungle Scout反查用于容量研究时，未提供key即跳过；Sorftime无key走Flapen＋ASINSIGHT，并按字段报告缺口。

## 核心关键词：CPC竞价

可用amazon-keyword-analysis时优先用其网页流程深入研究核心词、长尾词、需求、自然与广告竞争及竞价，按其输出约定写回选品表。没有该技能时继续执行下面的独立流程；关键词初筛仍占20%，竞争仍占25%，不重复加分。

在Amazon广告后台的关键词投放／竞价界面查询核心词及高相关长尾词。记录原词、站点、日期、货币、匹配类型（广泛／词组／精准）、建议竞价及区间、广告类型、数据截图或导出来源。仅查看，不为查询创建或启动付费广告。已有广告记录另列实际CPC及统计周期；建议竞价不能写成已发生CPC。

同站点、同匹配类型对比竞价压力，不设置用户未指定的统一“低CPC”阈值。Flapen／ASINSIGHT的广告或流量观察可作辅助，后台竞价不可得时标明缺项，需要测算则向用户索取后台数据。

联动利润分析：以预计实际CPC做明确的假设情景，广告归因订单转化率CVR＝订单÷点击，广告归因客单销售额＝单件售价×每单件数（或用户实际客单额）。预计ACoS＝CPC÷(CVR×客单销售额)，目标ACoS下可承受CPC＝目标ACoS×CVR×客单销售额。采用相同收入、币种和归因口径；未知CVR、每单件数或收入基础时先向用户追问，不能靠竞价直接推算ACoS或利润。执行完整利润测算时按利润技能必要输入关卡处理。

## 产品竞争：店铺实力

按代表竞品关联真实seller ID及品牌店铺，区分品牌所有者和销售方。逐项记录观察、证据、缺项以及对自有方案的影响：

| 判断项 | 对应工具与动作 |
|---|---|
| 评论数量与星级 | Amazon商品页／Sorftime或降级数据；比较多款产品的累计评价、近期增长、评分和重复差评，区分店铺feedback与商品评价 |
| 品牌商标 | Amazon品牌页、目标销售国家的官方商标数据库；查权利人、状态、类目、品牌一致性；A+或品牌名不能证明商标注册 |
| 国家、地区 | Amazon卖家公开公司信息；记录原始主体、国家／地区和来源，不从卖家名字猜测实力或实际所在地 |
| 产品列表 | 卖家产品列表／品牌店铺；记录在售SKU、类目集中度、系列尺寸颜色覆盖、新品和相邻扩品，说明未覆盖范围 |
| 文案与图片 | 商品详情页；比较本地化、卖点、适配说明、实拍／场景图、A+和视频，指出可见差距与实现成本 |
| 站外推广 | Keepa辅助查看价格、BSR及可获得的促销变化，网页搜索ASIN、品牌及产品名，核查品牌官网、公开社交媒体、测评／联盟内容、促销站点及可访问的广告资料库；记录渠道、推广链接、日期、活动及频次；仅凭查不到结果不能断言无站外推广 |

[Keepa历史记录](https://github.com/keepacom/api_backend/blob/master/src/main/java/com/keepa/api/backend/structs/Product.java)可帮助定位需核查的活动时间，但价格下降或BSR变化本身不能证明站外推广，也不能据此推断具体渠道；能否显示某种促销字段以实际权限与数据为准。站外推广查询记录搜索式、日期范围及已查渠道。命中页面需核对品牌／ASIN对应关系，区分官方、付费、联盟、用户自发内容与无法确认的推广；频次只是所查样本，不推算未公开的预算或销售贡献。商标正式状态以[USPTO](https://www.uspto.gov/trademarks/search)或对应国家官方数据库为准。

## 写入与评分

在“竞争分析”页按层级和方法保存：研究对象、指标、观察／数值、单位、样本范围、统计定义、覆盖状态、判断规则、信号／分析、来源、日期、数据状态与限制。在主表“竞争程度”写有证据的摘要，引用具体指标／店铺；在“类目判断”记录三个层次的结论、工具路径和缺口。

维持原四维权重，不为增加指标重复奖励竞争分：1分为明显集中、自营或评论／SKU壁垒且缺可行切入点；3分为部分友好信号、词或店铺进入点仍待验证；5分需要类目机会、关键词广告承受力、店铺／SKU切入空间都有证据支撑。2／4分为相邻情况，关键证据未知留空；初筛可先依据已得线索评分并明确限制，深度研究仍需完成三层分析。方向性信号和单项达标都不能替代综合进入判断。

工具能力核查：2026-10-12。[Sorftime](https://www.sorftime.com/en-US)、[Flapen](https://flapen.com/research/us)、[ASINSIGHT](https://www.asinsight.com/)、[Amazon Ads关键词投放](https://advertising.amazon.com/library/guides/targeting-with-sponsored-products/)。链接支撑工具能力，数值阈值来自用户。
