# 亚马逊选品

以市场容量、市场竞争、利润分析、关键词、差异化为主框架，最终交付Excel选品表。利润拥有一票否决权，其他优势不能抵消利润不达标。

## 输入与范围

沿用用户指定的站点、类目、核心关键词、预算、履约方式和文件路径。先确定阶段：初筛建立跨类目候选池，记录具体产品与来源、方法及初筛依据；深度研究以一个站点＋一个关键词或明确类目为一个前20采集组，多组分别输出工作簿。外部初筛候选暂时没有目标站点ASIN时保留来源，标记待确认。站点未指定时可暂用美国站并记录假设；方向全未知时先获取范围。

默认采用用户规则：目标ACoS为30%时，毛利率至少35%；推广为“毛利率≥目标ACoS＋5个百分点安全余量”。两项参数可调整，30%是用户广告情景而不是类目实测值。毛利不达标直接否决；达标后还需完整成本下净利润>0。缺成本标记待验证，不能作为通过。

模板请求输出 assets/亚马逊选品表.xlsx 的新副本，更新已知范围及日期，保持实采区空白。实际选品请求完成真实采集并填表。用户提供已有表时保持数据与布局，未经明确要求输出新文件。

## 执行

1. 读取 [selection-methods.md](references/selection-methods.md)，选择适合已有权限与资源的发现渠道；记录主方法与辅助方法，不必执行全部。根据证据做初筛，按方法优缺点调整研究优先级，去重且不重复计分。
2. 读取 [research-method.md](references/research-method.md)，确认五项分析、可比规格与利润规则。仅初筛请求可先交付候选池和分数，缺利润保持待验证，不把初筛入选当最终可做。
3. 收集市场容量与关键词证据；深度研究采集前20，分析评论壁垒、SKU、新品和错配。保存来源及状态；不足20条保留缺口，跨类目初筛池不混算前20。
4. 获取1–3星差评，按三类归纳，提出差异化与验证方式。针对自有产品方案核查完整成本并执行利润否决，核查专利与A+。已知利润失败即使初筛分高也排除。
5. 读取 [workbook-schema.md](references/workbook-schema.md)，用 spreadsheets skill 与工作区运行时按JSON运行 scripts/write_selection.mjs，或填写用户表。
6. 重算并检查指定列、方法与初筛依据、权重合计、去重、阈值、利润否决及缺失值传递、来源和显示，交付.xlsx。

## 输出

选品表前18列固定为：

排名｜产品名称｜类目｜核心关键词｜ASIN｜价格｜评论数｜评分｜竞争程度｜变体数｜上架时间｜FBA/FBM｜进货价｜毛利润｜毛利率｜主要差评｜是否有专利｜是否A+

第19列增加“选品方法”。原“评分”仍是满分5星的商品评价星级；“初筛得分”独立命名、满分100。竞争程度用文字依据。右侧保存辅助方法、初筛维度、覆盖率和依据，以及来源、变体、完整成本、净利与否决状态，随行排序。

另有类目判断、市场与关键词、差评分析、选品方法、初筛规则。方法表列对应工具、优缺点、补验动作、方法优先分及启用渠道投入权重。候选初筛的市场容量、竞争、关键词、差异化权重默认30%／25%／20%／25%，利润独立否决。评分仅表示研究优先级，不表示成功概率。

## 完成

交付可打开的Excel。实际研究写实采数据与明确缺口；模板保持空白，示例不能冒充实采。每项结论可追溯，成本缺失不显示达标，利润否决不可被手动的积极结论抵消。错配只标记值得深查的链接，最终进入还需市场、关键词、竞争和差异化证据成立。
