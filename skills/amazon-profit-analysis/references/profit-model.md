# 单件利润模型

## 口径

每次以同一个站点、销售单位、规格、销售收入定义和币种计算。优惠后的售价P采用用户明确的含税/不含税口径；采购及物流等成本须转换为同一币种。T为尚需扣除的税费，与P的税口径核对。收入已经剔除的VAT不能再次在T扣除。

本模型毛利沿用选品表定义，未包含广告、仓储、税费、退货和运营分摊，避免与会计毛利混用：

```text
基础成本 G = 采购 + 头程 + 平台佣金 + 履约 + 包装及其他基础成本
毛利润 = P − G
毛利率 = 毛利润 / P
广告后利润 = 毛利润 − 单件广告成本
其他净成本 E = 仓储 + 尚需扣税费 + 退货损耗 + 运营分摊
完整成本单件净利 = 毛利润 − 单件广告成本 − E
单件净利率 = 完整成本单件净利 / P
```

完整成本单件净利是所列成本口径下的经营测算，不等于公司会计净利润。用户明确排除了费用时记录排除范围，结论只能适用于该范围。

## 广告与否决

ACoS=广告花费/广告归因销售额；TACoS=广告花费/总销售额。同周期、同商品、同收入分母下，TACoS=ACoS×广告归因销售额占比，这是上述定义的推导；占比不是广告订单数量占比。[Amazon Ads定义](https://advertising.amazon.com/en-gb/library/guides/acos-advertising-cost-of-sales)

默认目标ACoS30%、安全余量5个百分点。若广告模式为ACoS，则采用max(目标ACoS,本次测算ACoS)+余量作为最低毛利率；TACoS或单件金额模式仍采用目标ACoS+余量的既定进入门槛。实际广告费按各自分母计算。用户明确修改门槛时记录修改。

1. 毛利率低于最低毛利率：否决。
2. 毛利达到含边界的最低值，但完整成本净利≤0：否决。
3. 两项均通过：仅利润关卡达标；资料是估算时为情景达标，不代替真实盈利证明。
4. 必要输入不完整：必须向用户追问，不计算完整净利或判达标。

计算保留全精度，展示金额通常2位、利润率1–2位小数。不能先四舍五入把34.999%当成35%；只允许消除机器浮点误差的极小容差。

## 盈亏平衡与采购约束

广告前可用利润=N0=P−G−E。广告率的保本上限=N0/P，广告归因情景命名“保本ACoS”，整体订单情景命名“保本TACoS”。它包含仓储、税费、退货与分摊，不能用毛利率直接冒充保本ACoS。

混合ACoS模式且广告销售额占比s>0时，另可展示整体保本TACoS/s作为对应的ACoS上限；s=0时不除以0，显示该情景无广告归因销售额。若N0<0，说明零广告费也亏损，不将负阈值裁剪成健康的0。

按当前售价、非采购费用和广告参数固定计算：

```text
毛利门槛采购上限 = P×(1−最低毛利率) − 不含采购的基础成本
净利为正的采购边界 = P − 不含采购的基础成本 − 广告 − E
采购须 ≤ 毛利门槛采购上限，且严格 < 净利为正的采购边界
```

边界可能为负；说明当前非采购费用结构不可行。两个约束分别展示，避免把净利为0的价格称为可采购上限。报价变化影响费用时重新取得费用，不外推此局部固定成本计算。售价盈亏平衡、CPC上限或月利润只有在对应价格费率函数、转化率、销量等必要数据已提供时再分析。
