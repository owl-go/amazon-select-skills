# 利润网页分析报告

本技能只输出利润网页分析报告，不生成、填充或更新Excel选品表。复制[report-template.html](../assets/report-template.html)，填写核验后的输入与计算结果，保存为用户指定路径或amazon-profit-report-<站点>-<日期>.html。保持单文件HTML、内联CSS、无外部依赖，外部文本按HTML转义，来源保留实际链接；在可用的网页／报告预览端打开，并在对话中提供报告链接、利润结论及限制。

网页／文件能力缺失时交付完整可读报告并说明限制，不声称已完成网页展示。预览受限时核验结构并说明未进行视觉检查，不绕过限制。技能／模板请求只输出空模板，不追问真实商品费用，也不虚构利润。

## 报告内容

1. 范围与结论：产品／规格、站点、销售单位、币种、价格含税口径、广告分母、成本范围、日期；利润否决／利润门槛达标／情景达标／待补输入，附原因。
2. 输入与成本：售价、采购、头程、佣金、履约、包装其他、广告、仓储、税费、退货、运营分摊；单件金额、计算或分摊依据、来源、周期、实测／估算／假设状态。真实零费用附依据，未知不填0。
3. 计算结果：毛利／毛利率、广告成本、广告后利润、完整成本单件净利／净利率、最低毛利率、保本ACoS或TACoS、采购上限及严格净利边界，保持模型定义与完整精度判断。
4. 情景与敏感性：仅列用户要求且必要条件完整的情景，标明修改参数、依据与适用范围；无相关请求可以省略该表。
5. 缺项与下一步：必要输入、单位、口径和缺失影响，待答问题与实际限制；报表来源及估算不确定性。达到利润门槛不替代选品推荐或完整市场判断。

## 缺项关卡与交接

必要计算条件缺失时必须先向用户询问。网页可以显示已核验的局部输入与缺项，但不显示完整净利或达标，也不能以一份待验证网页报告结束尚可补齐的利润请求；补齐后重新计算并更新报告。用户确实无法提供时明确测算未完成及原因。

calculate_profit.mjs的JSON是内部计算结果，不是用户可读报告的替代品。衔接amazon-product-direction时返回核验输入、结果、广告分母、费用范围、来源和状态，由选品技能决定如何汇总并输出工作簿与推荐网页。不得为让整体选品通过而制造缺失成本或积极结论。
