# 必要输入与补充问题

每个金额对象采用 `{ "amount": 数值或null, "currency": "USD", "source": "报价/报表/用户说明", "status": "confirmed|estimate|scenario" }`。百分率采用小数，如30%写0.30。没有明确数据的金额保持null。来源与状态缺失时可以完成明确金额的算术，但结果标记待核验；零金额必须有说明。

## 所有单件完整利润的必要条件

| 输入 | 含义及缺项处理 |
|---|---|
| context.marketplace/currency | 站点及最终输出币种；不能混加人民币进货价和美元售价 |
| context.fulfillment | 沿用用户明确的FBA或FBM；未指定时填FBA并注明默认口径，混合履约分别测算 |
| context.unit | 例如1个、1套2件装；采购、物流和售价必须按同一销售单位 |
| context.price_tax_basis | 含税或不含税，税费金额须与此口径匹配，避免重复扣VAT |
| context.cost_scope_confirmed | 用户或完整报价/费用资料确认适用费用已覆盖，明确填true；缺省必须确认 |
| price | 优惠后的销售收入金额，包含本口径中的买家付运费；已反映优惠的价格不再扣相同折扣 |
| costs.purchase | 每个销售单位的采购成本；外币须汇率转换 |
| costs.inbound | 单件头程及该项承担的关税/入库费用；归属其他项的费用在来源中说明 |
| costs.referral | 当前站点、类目、价格适用的单件平台佣金；直接使用明确费用金额 |
| costs.fulfillment | FBA配送费或FBM末端运输/履约费用；明确是否已经含包装、仓储 |
| costs.packaging_other | 包装及其他基础成本，包含适用的入库配置、标签、附加交易费用等未归属项；零需说明 |
| costs.storage | 单件仓储分摊，包含适用的超龄库存/仓储附加费；未知必须询问 |
| costs.tax | 售价口径下尚需扣除的单件税费，注明类型；关税已在头程中时不再计入 |
| costs.returns | 每个销售单位的预期退货损耗，涵盖适用退款、处理、不可售损失扣除回收价值；不可只用退货率乘售价冒充真实损耗 |
| costs.overhead | 单件运营及固定费用分摊，包含适用月租、人工、软件等；明确排除时由用户确认0及范围限制 |
| advertising | 见下列分支；没有广告也需明确采用金额模式填0及依据 |

产品名称/ASIN/资料日期有助于追溯，缺失本身不阻塞确定金额的单件算术。ASIN不是必需条件。不可因缺SKU或销售件数而阻塞本来可完成的单件利润。

## 广告模式的条件

| mode | 必要参数 | 单件广告成本 |
|---|---|---|
| attributed_acos | acos | 售价×ACoS；对应广告归因收入的单位情景 |
| blended_acos | acos、revenue_share（0–1） | 售价×ACoS×广告归因销售额占总销售额比例；相同产品/单位、同期、同收入口径 |
| blended_tacos | tacos | 售价×TACoS，分母为总销售额 |
| unit_amount | scope=attributed或all_orders、unit_cost金额 | 明确分摊到该销售单位的广告费用 |

ACoS/TACoS可以高于100%，不因此当无效值；销售额占比必须在0–1。广告报表收入与售价的含税/退款定义不一致时，必须先让用户明确或提供对齐数据，再转换为同口径的比率/单件金额。若使用CPC与转化率推导广告成本，先确认点击/归因订单/销售件数定义、每单件数及税费收入口径，再转换为明确的单件金额，不仅凭CPC就计算。

policy.target_acos默认0.30，margin_buffer默认0.05，来自既定用户情景。广告模式和实际/预测广告率仍需明确；模板提供的0.30是已标明的目标情景，不可冒充报表实测。整体订单模式也保留目标ACoS毛利门槛，不能自动降低为TACoS加余量。

## 条件依赖

- 金额币种不同：提供fx数组，包含from、to、rate（1单位from兑换多少to）、source、date。脚本只用直接方向，不自动倒数或拼接未核实的交叉汇率。
- 总运费：需要本批对应可售销售单位数及费用范围；总费用÷销售单位数。不要求重量数据，除非需要核实计费。
- 月度仓储/运营费用：需要相同周期费用及明确采用的可售量/销售量分摊方法，不能将一个月成本当永久单位成本。
- 退货率模型：需要单次退货净损失及依据，用退货概率×净损失；确认采购、退款、税费、佣金退款没有重复计入。
- 需要查采购或FBA费用：先执行下节查询；公开资料仍缺阻塞计算的必要条件时，向用户索取实际缺项。
- 用户提供的估算／预算和按下节核验的1688报价／FBA费用可作为输入，按资料实际性质标明来源及已确认／估算／情景状态；其他未知费用仍执行缺项追问，不用行业均值或默认值补齐。
- 必要额外费用归入上述适当成本项并记录组成，或扩展模型。未定义的costs键会阻止计算，避免静默遗漏移除、报废或附加费用。

## 采购查价与FBA费用

### 1688采购查价

采购价未提供时，先自行用产品名称、中文规格关键词或可用的图片搜索能力检索1688；用户指定其他供应渠道时沿用。图片搜索不可用时继续名称检索。已有可用报价直接核验，不重复让用户寻找同一金额。

- 核对拟销售单位对应的SKU、材质、尺寸、件数及包装，记录商品链接、报价币种、MOQ／数量阶梯、价格对应规格、国内运费及采集日期。已匹配的公开报价可作有来源的采购估算，标明不是已成交成本。
- 起价、混售SKU、单件与套装不同、配件缺失或材质／规格冲突时，保留为采购线索，正式采购输入仍为null。不能仅凭标题或相似图片把最低价当整套采购价；国内运费也不能当国际头程。
- 查询受限或无法匹配价格时，列明已查来源和仍缺的规格／报价，请用户补充。仅做网页研究不代表授权联系供应商、询价发送消息或下单。

### FBA默认口径与费用核验

未指定履约方式时采用FBA，报告注明默认；明确指定FBM时使用FBM成本分支。默认FBA不代表配送、仓储或入库费用已有金额。

- 使用当前站点的Amazon Revenue Calculator、Fee Preview或官方费用资料，核对适用类目、价格、销售单位、最终包装尺寸／毛重及费率生效期间，记录来源和查询日期。参考竞品ASIN的费用只适用于其包装，未经匹配不能直接作为自有方案的最终费用。
- 区分佣金、配送、入库配置、仓储及其他适用费用，确认与头程或包装项目没有重复；计算器空白成本、默认库存／销量和工具余额不能当业务数据或完整净利。
- 已取得适用的明确单件费用时直接使用，不为同一费用再索取无关尺寸。仍需推导费用时，先从可核验商品／报价资料取数；尺寸重量异常、单位不明或包装未确定时，请用户补充真正必要的包装尺寸、毛重、销售规格或适用期间。

## 追问示例

按真实缺项删减，一次提出少量成组问题：

> 目前还缺单件头程、FBA配送费、仓储和退货损耗，无法计算完整净利。请按美元/每个2件装补充四项金额，或提供对应报价/费用截图里的数值。确实没有的费用请填0并说明；有费用但暂不知道请写“未知”。

> 你提供的是ACoS30%，本次是算广告订单还是全部订单的利润？如果是全部订单，请补充同周期TACoS，或广告归因销售额占总销售额的比例。

> 进货价为人民币、售价为美元。请提供采用的人民币→美元汇率及日期，或授权使用当前汇率做明确标注的情景。

已有30%广告目标和5个百分点余量时，不再追问这两个已知偏好。补完一项而其他项仍缺失时继续保留其他问题，不能因收到部分回答就计算完整净利。
