# 类目竞争分析

规则来自用户。每项是进入门槛或新手友好信号，不是平台官方标准或成功概率；类目机会仍需容量、自有方案利润、关键词与差异化证据。模板请求只输出空表，实际分析取得来源后才形成结论。

## 工具与范围

有用户提供的可用Sorftime key时优先使用BSR市场分析；无key直接降级Flapen＋ASINSIGHT，并用Amazon榜单、商品页、卖家页或用户导出补证。报告保留所用路径和逐项覆盖；密钥只经当前agent安全凭据渠道使用。接口、字段与权限按实际官方文档核验。

[Flapen](https://flapen.com/research/us)用于细分市场、评论与品牌门槛和可得产品信息；[ASINSIGHT](https://www.asinsight.com/)用于ASIN、关键词、排名与流量集中观察。niche或关键词样本不是类目BSR Top100，关键词Top3点击／转化占比不是类目品牌或店铺垄断率。替代工具不覆盖字段时留空，先完成可得部分，再按需要向用户索取导出或截图，不因无Sorftime key而停止全部研究。[Sorftime官方说明](https://www.sorftime.com/en-US)支持类目Top100市场分析。

固定站点、配送地区、细分类目节点、榜单地址、采集日与统计周期。保留榜单排名、ASIN、父体、品牌、seller ID、上架日期、评价数量、星级、销售方、FBA／FBM、A+、视频与来源。评价数量和1–5星商品星级分别记录；评级总数与文字评论数统一口径，父体共享另注明。

## 方法一：BSR Top100

默认以榜单100个条目为分母，记录父子体共享。如工具已合并父体，另报实际数量和去重规则，不把不足100条称完整Top100。日期、评价、销售方等分别报告有效数；未知不按0计算，相关比例／判断保持待验证。容量的销量去重口径与此榜单条目口径分别记录。

| 指标 | 用户规则 | 统计定义与核验 |
|---|---|---|
| 近3个月新品占比 | ≥10%为新手友好信号 | 新品数÷完整Top100；采集日前3个日历月至采集日，含首尾边界 |
| 近6个月新品占比 | ≥20%为新手友好信号 | 同上，窗口6个日历月；两个信号分别报告，不额外要求同时满足 |
| 上架时间分布 | 新品占比越大，机会越多 | 展示3／6／12个月及更早；窗口可重叠；Date First Available是代理值，核查父子迁移 |
| 评论时间分布 | 用户原图左侧多竞争小，右侧多竞争大 | 记录横轴、时间方向、区间和统计对象；轴方向相反按实际含义解释，轴未知待验证 |
| 评论数量分布 | 低评论区多竞争小，高评论区多竞争大 | 横轴从低到高时对应左低右高；保留各桶数量，不以均值代替分布 |
| 品牌垄断程度 | <45%可接受 | 保留原工具品牌聚合范围、分子、分母、周期，45%不通过此信号 |
| 店铺垄断程度 | <45%可接受 | 按seller ID区分品牌与卖家；保留TopN／销量／销额等原定义，45%不通过 |
| Amazon自营占比 | <19%为有利信号 | 按实际销售方识别，FBA是履约方式，不能当自营；19%不通过 |
| FBM占比 | 越高越有利 | 同口径对比类目或历史，注明基准；无固定通过线 |
| A+视频占比 | 越少越有利 | 先记录工具定义；A+、视频、两者同时分别统计；无固定通过线 |
| 整体星级 | 越低越有改善机会 | 标明简单平均或销量加权及覆盖，结合可解决的1–3星质量／适配／场景差评 |

“上架年龄×评论数”图不能称买家评论日期分布，左右位置转成实际区间再解释。较低星级需确认差评可改善、增量成本可承受。

垄断定义缺失时索取原报告口径，或明确使用代理观察并说明范围；代理指标不能冒充原垄断率套用45%阈值。只拿到部分样本时报告已知数、覆盖及可能上下界，不能只对已知样本计算较小的比例宣称通过。

## 方法二：BSR Top50低评论卖家

同站点、同细分类目榜单前50，记录排名、ASIN、父体、评价数量、口径和代表销售方seller ID。筛选评价数严格<1000的条目，以seller ID去重；去重低评论卖家数严格>20，即至少21家，为新手友好信号。

同一卖家多款低评论商品仍只计一家。同时显示低评论商品数、去重低评论卖家数、总卖家数、评价和身份覆盖。恰好1000不计，恰好20家不通过。评论／身份缺失、不足50条时保留已知下限和缺项，不冒称完整判断。店铺feedback数与商品评价数量分别保存。

## 合并结论与交接

两种方法互补，实际可得哪条先做哪条，均可得时交叉核验。冲突需解释范围、统计定义、数据时间和样本，不能任选有利结果当整体结论。原关键词自然结果前20的评论、SKU、近一年新品与错配由选品技能另行执行，Top100／Top50／前20分别保存。

报告使用“类目存在机会／进入门槛较高／信号混合／待验证”等有依据的文字，说明友好信号、主要壁垒、可切入空间、缺项和下一步；不给新品、垄断、FBM、低星级重复奖励一个额外分数。进入选品初筛时，竞争仍按原25%维度综合评估，单项达标不能自动推到5分或覆盖利润否决。

写入竞争证据表：指标、对象、数值／观察、单位、样本范围、定义、有效数／覆盖、规则、信号／分析、来源、采集日、数据状态、限制。状态区分实测／估算／假设／待采集，零必须有依据；经验阈值的来源写用户规则，实际指标的来源写报告／页面。工具能力核查日期：2026-10-12。
